# 配慮モード

設定 → 配慮モードから有効にする。初期状態はオフ。

- モバイル通信、未登録Wi-Fi、SSID不明、未接続、VPNでは有効。
- 許可リストにSSIDが完全一致するWi-Fiだけで解除。
- SSID照合には正確な位置情報の権限と端末の位置情報オンが必要。座標の取得・送信は行わない。
- SSIDは端末内のSharedPreferencesに保存し、バックアップ対象外。SSIDはアクセスポイントの真正性を保証する識別子ではない。
- 接続変更、アプリのバックグラウンド移行、設定変更時は個別の表示許可を取り消す。

## メディアの扱い

ポスト・引用・DMの添付メディアと共通動画コンポーネントが対象。
アバター・静止画のプロフィールヘッダーなど、添付メディア以外の画像は対象外。

APIのsensitive指定は従来どおり接続先に関係なく初期非表示。
配慮モード中、静止画は同梱モデルによって端末内で判定する。
スコア0.4以上・判定エラー・未対応形式は非表示にする。
動画・GIF・検出したアニメーション画像は一部フレームから全体の安全性を判断せず非表示。
「静止画を端末内で判定」をオフにすると、配慮モード中は全添付メディアを非表示にする。
利用者が「このメディアを表示」を選ぶと、その表示中に限って開く。

判定前・非表示中は画像コンポーネントや動画プレーヤーを生成しない。
判定用の静止画は元の配信元から取得するため通信量がかかる。
判定用バイト列はメモリ内で処理し、ディスクへの保存・外部AIへのアップロードは行わない。
通常の画像表示で用いるキャッシュ設定は別。
推論は直列化し、取得上限12MiB、デコード時の縮小を適用。

## モデル

Yahoo Open NSFW由来のTFLiteモデル、約22.5MiB。
配布元・固定リビジョン・SHA-256・ライセンスは `app/src/main/assets/care/NOTICE.txt` 参照。
実行エンジンは同梱のLiteRT 1.4.1。Google Playサービスやクラウド推論は使用しない。
性的コンテンツ向けの推定であり、見逃し・誤判定がある。暴力表現など全センシティブ分野を網羅しない。

## 検証

`gradlew.bat :app:testDebugUnitTest` — 配慮モードの接続条件とアニメーション識別。

`gradlew.bat :app:connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=dev.rec877.north.OnDeviceClassifierTest`
— 単色の人工画像でモデルの入出力、表示許可前のコンテンツ非生成、動画・センシティブ指定の取得抑止を確認。
モデルの判定精度評価や実際のWi-Fi切替試験を代替するものではない。
