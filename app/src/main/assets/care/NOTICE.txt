The preprocessing follows this distribution: 224x224 float32 BGR,
channel means 103.939 / 116.779 / 123.68; output index 1 is the NSFW score.
North hides images at score >= 0.4. This is a conservative heuristic, not
a guarantee or calibrated probability. Videos and animated images remain hidden.

Inference runs entirely on this device using LiteRT; no image or score is
uploaded to a model provider. Normal authenticated media downloads still occur.
The model is not a comprehensive classifier for violence or all sensitive topics.
